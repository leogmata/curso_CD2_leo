# curso_CD2_leo
Projeto final para o curso Ciência de Dados Aplicados à Epidemiologia II

Este projeto foi desenvolvido no âmbito da disciplina Ciência de Dados Aplicados à Epidemiologia II, com o objetivo de explorar, de forma aplicada, conceitos de análise de dados, modelagem ambiental e visualização espacial utilizando a linguagem R e aplicações interativas em Shiny. Trata-se de uma proposta com caráter essencialmente educacional, voltada para a compreensão de como variáveis ambientais, como a temperatura, podem ser construídas de forma plausível, analisadas e visualizadas tanto em ambiente de programação quanto em aplicações web.

O projeto está estruturado em dois componentes principais. O primeiro consiste em um script em R, no qual são realizadas as etapas de obtenção das estações meteorológicas, construção das temperaturas máximas plausíveis e interpolação espacial. A partir dos dados das estações disponíveis no pacote BrazilMet, são gerados valores de temperatura baseados em critérios climáticos e geográficos, incluindo latitude, altitude, proximidade do litoral e domínio climático predominante. Esses fatores são combinados de forma a produzir uma superfície de temperatura coerente com a realidade brasileira, ainda que simulada. Posteriormente, é aplicada uma interpolação espacial por meio do método IDW (Inverse Distance Weighting), permitindo estimar valores de temperatura em áreas não observadas e gerar mapas contínuos.

O segundo componente do projeto é uma aplicação web desenvolvida em Shiny, que possibilita a exploração interativa dos dados. Nessa aplicação, o usuário pode visualizar o mapa da temperatura interpolada sobre o território brasileiro, com a sobreposição dos limites estaduais e a localização das estações meteorológicas. Há também a possibilidade de destacar uma estação específica, facilitando a análise individualizada. Além disso, a aplicação apresenta um conjunto de ferramentas analíticas, incluindo um gráfico interativo da distribuição das temperaturas máximas, no qual são exibidas a curva de densidade, bem como as linhas de média e mediana, permitindo uma compreensão mais intuitiva da distribuição dos dados.

Uma das principais funcionalidades da aplicação é a possibilidade de manipulação dos valores de temperatura. O usuário pode inserir valores manualmente para uma estação específica, o que é útil para simulações dirigidas e testes de cenários. Alternativamente, pode optar pela geração automática de valores aleatórios plausíveis, seja para uma única estação ou para todas as estações simultaneamente. Esses valores são gerados com base no mesmo modelo climático utilizado no script, garantindo coerência espacial e ambiental. A tabela de dados exibida na aplicação também é editável, permitindo ajustes diretos nos valores e atualização imediata das visualizações.

Outro recurso importante é a possibilidade de exportação dos dados. A aplicação permite o download de um arquivo em formato CSV contendo as informações das estações, incluindo código da estação, município, unidade federativa, altitude e temperatura máxima. Essa funcionalidade amplia o potencial do projeto, permitindo que os dados gerados sejam utilizados em análises posteriores, em outros softwares ou em diferentes etapas de estudo.

A construção das temperaturas segue um princípio de plausibilidade, não representando dados observados reais, mas sim valores simulados com base em regras climatológicas. Foram considerados efeitos como o gradiente latitudinal, em que regiões mais próximas ao equador tendem a apresentar temperaturas mais elevadas; o efeito da altitude, que reduz a temperatura conforme aumenta a elevação; a influência do litoral, que tende a moderar as temperaturas; e a diferenciação entre domínios climáticos, como Amazônia, semiárido, cerrado e regiões subtropicais. Além disso, foi incorporada uma componente aleatória controlada, de forma a representar a variabilidade natural dos fenômenos ambientais. Os valores finais são limitados a um intervalo entre 0°C e 40°C, garantindo consistência com condições típicas do território brasileiro.

Por fim, destaca-se que este projeto não tem como finalidade substituir bases de dados reais, mas sim servir como uma ferramenta didática para o aprendizado de técnicas de ciência de dados aplicadas à epidemiologia. Ao permitir a construção, manipulação, visualização e exportação de dados simulados, o projeto oferece um ambiente completo para experimentação e desenvolvimento de habilidades em análise espacial, modelagem e visualização interativa
